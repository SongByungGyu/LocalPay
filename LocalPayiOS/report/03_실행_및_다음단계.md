# 03. 실행 방법 · 검증 결과 · 다음 단계

## 실행 방법

### 사전 준비

- Xcode 16 이상 (개발은 26.4 에서 확인)
- Homebrew
- `xcodegen` (`brew install xcodegen`)

### 빌드 & 실행

```bash
cd LocalPayiOS

# project.yml 로부터 .xcodeproj 재생성 (파일 추가/이동/삭제 시마다)
xcodegen generate

# Xcode 에서 열기
open LocalPay.xcodeproj

# CLI 빌드 검증
xcodebuild \
  -project LocalPay.xcodeproj \
  -scheme LocalPay \
  -destination 'generic/platform=iOS Simulator' \
  -configuration Debug clean build
```

Xcode → Scheme `LocalPay` → iPhone 15/16 시뮬레이터 → Run.

### 시뮬레이터에서 확인할 시나리오

1. 앱 실행 → 안양 지도 표시 (위치 권한 프롬프트 뜨면 아무거나 선택)
2. 상단 결제 필터 "온누리" → 온누리 미지원 마커 사라짐
3. "카페" 카테고리 → 카페 마커만 남음
4. 카페 마커 하나 탭 → 하단 Preview 등장
5. "상세보기" → 사용 가능 결제 / 판매 상품 / 최근 결제 확인 / 후기 확인
6. 상세 우상단 하트 → 즐겨찾기 등록
7. Preview 상단 "후기 작성하기" → 시트로 별점 · 내용 입력 → 등록 → 후기 목록에 즉시 반영
8. 하단 Tab "즐겨찾기" → 등록된 매장이 카드로 뜸
9. 앱 종료 후 재실행 → 즐겨찾기 / 사용자 후기 유지 확인
10. Tab "검색" → "삼겹살" 입력 → 결과 카드 리스트 → 정렬 변경 확인
11. Tab "MY" → 프로필 · DEMO 잔액 · 지역화폐 혜택 카드 · 스탯 반영

## 알려진 한계 · 정리 항목

- **`extension String: @retroactive Identifiable`** (`MapHomeView.swift`) — `navigationDestination(item:)` 편의용으로 파일 최하단에 위치. 프로젝트 전역에 영향 있으므로, 실 서비스 전 별도 wrapper (`IdentifiableID`) 로 대체 검토.
- **거리 계산 기준점** — 현재 `MapRegion.anyangDefault.center` 를 기준으로 초기 계산. 향후 지도 카메라 중심 반영으로 개선 필요.
- **매장 대표 이미지 자산 없음** — 카테고리 아이콘 + 결제색 그라디언트로 대체. 실 이미지 파이프라인은 서버 도입 후.
- **Cluster 미구현** — 안양 25개 규모에서는 불필요. 전국 규모 확장 시 필요.
- **Unit / UI Test 미작성** — `Utilities/*`, `SortOption`, `DummyMerchantRepository`, `FavoritesStore`, `ReviewsStore` 부터 우선 도입.
