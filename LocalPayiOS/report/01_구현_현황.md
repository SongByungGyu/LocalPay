## 화면별 기능 정리

### 지도 (Map Tab)

**파일**: `Features/Map/MapHomeView.swift`, `MapHomeViewModel.swift`, `MerchantPreviewCard.swift`

- iOS 17 신 Map API (`Map(position:selection:)` + `Annotation`)
- 초기 카메라: 안양시청 근방 (`MapRegion.anyangDefault`, 위치 권한 거부 시 fallback)
- **상단 오버레이**
  - Floating SearchBar (탭 시 검색 유도)
  - 결제수단 Filter (`전체 / 온누리 / 지역화폐 / 둘 다`)
  - 카테고리 가로 스크롤 (`전체 / 음식점 / 카페 / 약국 / 마트 / 시장 / 식품 / 미용 / 생활 / 기타`)
  - DEMO 뱃지 상시 표시
- **마커** — 결제수단 색 (온누리 초록 / 지역화폐 주황 / 둘 다 파랑) + 카테고리 SF Symbol + 선택 상태 애니메이션
- **우하단** — FloatingLocationButton (권한 상태에 따라 아이콘 변경)
- **하단 시트** — 마커 탭 시 MerchantPreviewCard (bottom-in transition)
- **에러 상태**
  - 위치 권한 거부 시 상단 배너 (설정 유도, 앱은 계속 사용 가능)
  - 필터로 결과 0건 시 상단 chip 표기
- **네비게이션** — Preview "상세보기" 탭 → NavigationStack push → `MerchantDetailView`

### Merchant 상세

**파일**: `Features/MerchantDetail/MerchantDetailView.swift`, `MerchantDetailViewModel.swift`

- 헤더 배너 (카테고리 아이콘 + 결제수단 색 그라디언트, 실 이미지 자산 없이 시각적 정체성 확보)
- 이름 · 카테고리 · 별점 · 후기 수 · 거리 · 설명
- **사용 가능한 결제** 섹션 — 지원 상품권 나열 + 지역화폐 브랜드명(예: 안양사랑페이)
- **판매 상품** 섹션 — `ProductChipFlow` (자동 줄바꿈 Layout 자체 구현)
- **가게 정보** 섹션 — 주소 · 전화 · 영업시간 · 시장명 · 최근 확인일
- **최근 결제 확인** 섹션 — `PaymentVerification` 로그 (DEMO 뱃지)
- **후기** 섹션 — seed 후기 + 사용자 작성 후기 병합 · 최신순
- 우상단 즐겨찾기 하트
- **후기 작성 시트** — `ReviewComposerView` (별점 · 내용 · 결제수단 Picker · 결제 인증 Toggle · 구매상품). 저장 시 `ReviewsStore` 에 append → 즉시 목록 반영

### 검색 (Search Tab)

**파일**: `Features/Search/SearchHomeView.swift`, `SearchViewModel.swift`, `SortOption.swift`, `Components/MerchantCard.swift`

- Search Bar + 실시간 debounce (300ms)
- 추천 키워드 chip (삼겹살 / 약국 / 카페 / 떡 / 안양중앙시장 / 안양사랑페이)
- 결과 상단 정렬 selector (거리순 / 평점순 / 후기순)
- 결과 카드 (`MerchantCard`): 카테고리 썸네일 + 이름 + 거리 + 별점 + 결제뱃지 + 대표 상품 3개 + 즐겨찾기
- 카드 탭 → 상세로 이동
- 상태별 UI: 검색 전 안내 / 검색 중 스피너 / 결과 없음 안내

### 즐겨찾기 (Favorites Tab)

**파일**: `Features/Favorites/FavoritesHomeView.swift`, `FavoritesStore.swift`

- `FavoritesStore` (`@Observable`) — UserDefaults 로 즐겨찾기 ID 집합 영속화
- 빈 상태 EmptyStateView (하트 아이콘 + 지도에서 저장 유도)
- 저장된 매장을 `MerchantCard` 로 렌더링
- 상세로 push
- 즐겨찾기 변경 시 자동 재로딩 (`onChange(of: favorites.ids)`)

### MY (MyPage Tab)

**파일**: `Features/MyPage/MyPageHomeView.swift`, `BalanceCard.swift`, `CurrencyPolicyCard.swift`

- 프로필 헤더 (닉네임 "병규님", 기본 지역 "경기 안양시")
- 스탯 타일 3열 — 즐겨찾기 수 / 내 후기 수 / 결제 인증 수 (실 데이터 연결됨: FavoritesStore, ReviewsStore)
- 내 상품권 섹션
  - `BalanceCard(.onnuriDigital)` — 128,500 원
  - `BalanceCard(.anyangSarangPay)` — 43,200 원
  - Toggle 로 DEMO 금액 표시 On/Off (Off 시 "잔액 연동 준비 중" 문구)
- 지역화폐 혜택 섹션
  - `CurrencyPolicyCard` — 안양사랑페이 · 이번 달 충전 혜택 7% · 월 구매한도 30만원 · 정보 기준일 2026.08
- 설정 섹션 — 기본 지역 · 알림 설정 · 앱 정보 (v0.1.0)
- Footer — "Dummy MVP 이며 실제 API 미연결" 안내
- 모든 잔액 · 정책 카드에 **DEMO** 뱃지 상시 노출

## Empty / Loading / Error 상태 커버리지

| 상태 | 화면 | 구현 |
|---|---|---|
| 검색 전 안내 | Search | EmptyStateView "무엇을 찾아드릴까요?" |
| 검색 중 | Search | LoadingView 스피너 |
| 검색 결과 없음 | Search | EmptyStateView "검색 결과가 없어요" |
| 즐겨찾기 없음 | Favorites | EmptyStateView "아직 즐겨찾기가 없어요" |
| 위치 권한 거부 | Map | LocationDeniedBanner (상단) |
| 필터 결과 없음 | Map | NoMerchantChip (상단) |
| 상세 로드 실패 | Detail | EmptyStateView + "다시 시도" 버튼 |
