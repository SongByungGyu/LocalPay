## 2. MAP-01 지도 홈

### 목적

앱 진입 즉시 주변 상품권 사용 가능 가맹점을 보여준다.

### 구성 요소

1. 상단 검색창
2. 결제수단 Filter Chip Row
   - 전체
   - 온누리
   - 지역화폐
   - 둘 다
3. Category Chip Row
   - 전체
   - 음식점
   - 카페
   - 약국/의료
   - 마트
   - 시장
   - 식품
   - 미용
   - 생활
   - 기타
4. 지도
5. 가맹점 Marker
6. Cluster Marker
7. 내 위치 버튼
8. `이 지역에서 다시 검색` 버튼
9. 선택 매장 Bottom Peek Card
10. Loading / Empty / Error overlay

### 기본 동작

- 앱 최초 실행: 위치 권한 요청 전 설명 UI 제공
- 권한 허용: 사용자 위치 기준 지도 이동
- 권한 거절: 기본 지역 또는 마지막 본 위치 표시
- 지도 이동 완료 후 카메라 bounds 저장
- 사용자가 충분히 이동했을 때 `이 지역에서 다시 검색` 노출
- 버튼 탭 시 현재 bounds 기준 repository 조회

### Marker 표현

- 온누리만: 온누리 타입 컬러 + 단일 아이콘
- 지역화폐만: 지역화폐 타입 컬러 + 단일 아이콘
- 둘 다: 복합 타입 컬러/아이콘
- 선택 상태: 크기 증가 + 테두리/그림자

### Cluster

- 개별 Marker 과다 노출 방지
- 숫자 표시
- 탭하면 해당 영역 확대

## 3. SRH-01 통합 검색

### 검색 대상

- 가맹점명
- 시장명
- 카테고리
- 취급상품/대표상품
- 주소/동 이름

### 검색 UX

입력 예:

- `삼겹살`
- `약국`
- `안양중앙시장`
- `커피`

검색어가 없는 경우:

- 최근 검색어
- 카테고리 바로가기
- 최근 본 매장

### 검색 결과 항목

- 매장명
- 카테고리
- 거리
- 지원 결제수단
- 대표 상품 최대 2개
- 평점/후기수(자체 데이터가 있는 경우)
- 최근 사용자 결제 확인 시점

### 정렬

MVP:

- 가까운 순
- 이름 순
- 최근 확인 순

Phase 2:

- 추천순
- 후기 많은 순

## 4. DET-01 가맹점 상세

### Header

- 가맹점명
- 카테고리
- 즐겨찾기
- 공유(Phase 2 가능)

### 결제수단 영역

예:

- 디지털 온누리 가능
- 지류 온누리 가능
- 카드형 온누리 정보 있음/없음
- 지역화폐: `OO사랑상품권`

주의: 데이터가 없으면 “불가”가 아니라 **“확인 정보 없음”**으로 구분한다.

### 기본 정보

- 주소
- 거리
- 전화
- 시장명
- 영업상태
- 영업시간(확보 시)
- 데이터 업데이트 시각

### 상품/서비스

- 대표 상품 Chip
- 취급 품목 목록
- 데이터 출처 배지

### 최신성/결제 확인

- `최근 사용자 결제 확인 3일 전`
- 온누리/지역화폐별 최근 성공일
- 실패 신고가 최근 발생하면 경고 문구

MVP는 더미 데이터로 표현한다.

### 후기

- 평점
- 후기 개수
- 최근 후기 2~3개
- 전체 보기
- 후기 작성

### CTA

- 전화
- 길찾기
- 후기 작성

길찾기는 Kakao Navi 또는 외부 지도 앱 연결을 Phase 2에서 결정 가능하며, MVP에서는 intent/deeplink 인터페이스만 준비한다.

## 7. MY-01

### 구성

1. 사용자 영역
2. 내 상품권
3. 기본 지역
4. 내가 쓴 후기
5. 결제 인증
6. 설정
7. 서비스 정보

### 내 상품권 MVP 정책

실제 개인 잔액 API가 확보되지 않은 상태에서는 다음 중 하나를 사용한다.

- Development Build: 더미 잔액임을 표시
- Production MVP: `잔액 연동 준비중` + 공식 서비스 이동

절대로 HTML 파싱/비공개 API/사용자 계정 자동로그인으로 잔액을 수집하지 않는다.

## 8. 상태 정의

모든 데이터 화면은 다음 상태를 갖는다.

- Initial
- Loading
- Content
- Empty
- Error
- Offline

### 예: 지도 Empty

> 이 지역에서 조건에 맞는 사용처를 찾지 못했어요.  
> 카테고리 또는 결제수단 필터를 바꿔보세요.

### 예: 네트워크 Error

> 정보를 불러오지 못했어요.  
> 잠시 후 다시 시도해주세요.

## 9. 필터 규칙

### 결제수단 필터

`전체`
- 온누리 또는 지역화폐 정보가 하나라도 있는 매장

`온누리`
- `supportsOnnuri == true`

`지역화폐`
- `supportsLocalCurrency == true`

`둘 다`
- 두 값 모두 true

### 카테고리

Server/Domain에서 통일된 enum을 사용한다.

```text
ALL
FOOD
CAFE
PHARMACY_MEDICAL
MART
MARKET
GROCERY
BEAUTY
LIFESTYLE
FASHION
OTHER
```

## 10. 데이터 신뢰도 표현 규칙

### 값 세 상태

Boolean만 사용하지 말고 필요한 필드는 다음 상태를 고려한다.

- `SUPPORTED`
- `NOT_SUPPORTED`
- `UNKNOWN`

특히 공공데이터 부재를 `NOT_SUPPORTED`로 오판하지 않는다.

### 최신성

- `sourceUpdatedAt`: 데이터 제공기관의 갱신 시점
- `syncedAt`: 우리 서버 수집 시점
- `lastVerifiedAt`: 사용자/가맹점이 실제 확인한 시점

## 11. 알림/권한

### MVP 권한

- 위치 권한: 필요

- 카메라: 불필요
- 사진: 불필요
